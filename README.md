# Лабораторна робота №4 — FreeRTOS Mutex (Variant 9)

## Варіант
- IDX = 9  
- 3 задачі  
- Критичний ресурс: UART (printf)  
- Тип синхронізації: **Mutex**  
- Завдання: кожна задача друкує повідомлення у “UART” блоком; перевірити, що текст не перемішується.

## Що робить проєкт
Створюються три задачі (`User1`, `User2`, `User3`), які виводять у консоль 2–3 повідомлення.  
Доступ до “UART” захищений м’ютексом, тому кожен блок друку виконується цілісно.  
Mutex гарантує, що жодна інша задача не може друкувати одночасно.

## Як запустити
1. У `main.c` додати:
```c
extern void vStartLab4_Variant9(void);
vStartLab4_Variant9();
vTaskStartScheduler();
```
2. Додати файл:
```
lab4_variant9.c
```
3. Зібрати WIN32-MingW / MSVC → запустити.

## Приклад виводу
```
[User 1] >>> Begin message
[User 1] Working...
[User 1] <<< End message
[User 2] >>> Begin message
[User 2] Working...
[User 2] <<< End message
[User 3] >>> Begin message
...
```
## Висновки
При використанні Mutex вивід формується блоками і не перемішується між задачами.
Це підтверджує коректну роботу механізму взаємовиключення у FreeRTOS та правильний доступ до критичних ресурсів.
