\# Лабораторна робота №1 — FreeRTOS (Windows)



\## Тема

Вступ у FreeRTOS. Ознайомлення з базовими функціями.



\## Мета

Опанувати базові принципи створення задач, роботи з пріоритетами та періодичними викликами у FreeRTOS.



\## Варіант (ID = 7)

| Задача | Період (T, мс) | Час виконання (C, мс) | Пріоритет |

|---------|----------------|-----------------------|------------|

| τ1 | 13 | 3 | 2 |

| τ2 | 23 | 5 | 3 |

| τ3 | 41 | 5 | 1 |



\## Опис

Програма створює три періодичні задачі, кожна з яких імітує виконання роботи за допомогою `vTaskDelay()` та логування міток часу (tick).  

Було проведено експеримент з параметром `configUSE\_TIME\_SLICING` для аналізу джитера задач.



\## Як запустити

1\. Відкрити `WIN32.sln` у Visual Studio  

2\. Встановити `#define mainCREATE\_SIMPLE\_BLINKY\_DEMO\_ONLY 1`  

3\. Запустити (`F5`)
