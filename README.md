# Лабораторна робота №6 — FreeRTOS  
## Stream Buffer, Message Buffer, Event Groups  
**Варіант: 9 — Менеджер задач / Job-Scheduler**

### 📌 Опис проєкту
Демонстраційний проєкт реалізує спрощений job-scheduler, у якому задачі створюються, передаються через чергу та виконуються Worker-задачею. Для взаємодії задач використовуються три механізми FreeRTOS:

- **Stream Buffer** — логування “сирих” даних про jobs (ID, priority, timestamp).  
- **Message Buffer** — передавання структурованих job-повідомлень між задачами.  
- **Event Group** — координація станів системи (`JOBS_PENDING`, `QUEUE_OVERLOADED`, `WORKER_IDLE`, `JOB_FAILED`).

### 🧩 Структура задач
- **JobGeneratorTask** — створює jobs, надсилає їх у message buffer, пише raw-лог у stream buffer.  
- **JobQueueTask** — приймає jobs, рахує чергу, сигналізує про переповнення.  
- **WorkerTask** — виконує job та встановлює системні події.  
- **MonitorTask** — відстежує біти подій і виводить стани системи.

### ▶️ Як запустити
1. Створити новий Win32 FreeRTOS проєкт (MSVC / MingW).  
2. Додати файл `lab6_var9.c` у проєкт.  
3. Викликати функцію запуску в `main()`:

   ```c
   vStartLab6_Variant9();
   vTaskStartScheduler();
   ```
4. Запустити проєкт. У консолі відображатиметься хід роботи генератора, черги, виконавця та монітора.

📄 Що демонструє проєкт
- циклічне формування та обробку jobs;
- взаємодію через stream buffer та message buffer;
- використання event groups для координації задач;
- базове моделювання job-scheduler системи.

✔ Висновок
У проєкті реалізовано повний цикл роботи менеджера задач із застосуванням ключових механізмів FreeRTOS. Поведінка системи відповідає вимогам варіанта №9 та демонструє практичні принципи багатозадачності.
