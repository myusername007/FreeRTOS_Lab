# Lab 5 — FreeRTOS (Variant 9)

Реалізовано модель *“завантажувача файлів”* з використанням трьох задач і двох таймерів.

## Задачі
- **ControlTask** — обробка команд користувача (start/stop/pause), підрахунок запусків.
- **DownloadTask** — симуляція завантаження блоками, передача прогресу в UiTask.
- **UiTask** — вивід прогресу або помилки таймауту.

## Таймери
- **Periodic timer (100 ms)** — генерує блоки завантаження через notification.
- **One-shot timer (1500 ms)** — сигналізує про таймаут, якщо прогрес не оновлюється.

## Використано
- direct-to-task notifications (семафор і value)
- періодичний та одноразовий таймери
- три задачі з чітким розподілом ролей

## Приклад роботи
```c
-[Control] START (attempt #1)
-[UI] Progress: 5%
-[UI] Progress: 10%
-[UI] Download complete!
```c
